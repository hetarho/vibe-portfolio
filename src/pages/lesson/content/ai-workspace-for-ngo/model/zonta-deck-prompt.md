# 역할
당신은 오리엔테이션 발표 자료를 만드는 제작 에이전트입니다.
새로운 사실을 지어내지 않고, 내가 준 근거표에 있는 내용만으로 슬라이드를 만듭니다.

# 재료
같은 폴더의 아래 두 파일을 읽고 시작하세요.
- zonta-근거표.xlsx
- zonta-조사보고.md

근거표에 없는 주장은 슬라이드에 넣지 마세요.
꼭 필요한데 근거가 없다면, 넣지 말고 "발표자 확인 필요" 목록에 적어 주세요.

# 발표 조건
- 청중: [지역 · 참석자 · Zonta 경험 수준]
- 발표 시간: [ ]분
- 슬라이드 수: 표지와 마무리를 포함해 [12]장
- 분위기: 앞으로 2년을 함께 시작하는 자리

# 만들기 전에 할 일
PPT 파일을 만들기 전에, 슬라이드 제목만 순서대로 적어서 먼저 보여주세요.
제목만 위에서 아래로 읽었을 때 이야기가 이어지는지 내가 확인하고 승인하겠습니다.
승인 전에는 파일을 만들지 마세요.

# 슬라이드 규칙
1. 한 장에 메시지 하나만 담습니다. 제목은 문장으로 씁니다.
2. 화면 글자는 한 장에 다섯 줄 이내, 한 줄은 스무 자 안팎으로 줄입니다.
3. 자세한 설명은 발표자 노트에 씁니다.
4. 숫자와 핵심 주장에는 근거표의 출처와 날짜를 슬라이드 아래에 작게 답니다.
5. 공식 자료로 확인된 사실과 우리의 해석을 같은 줄에 섞지 않습니다. 해석에는 "우리의 해석"이라고 밝힙니다.
6. 지역 현안처럼 공개 자료로 알 수 없는 것은 단정하지 말고 청중에게 던지는 질문으로 만듭니다.
7. 뒷자리에서 읽히도록 본문 글자는 24pt 이상으로 잡습니다.

   - 근거가 약해서 뺀 내용

# 지역별 버전
기본 파일이 완성되고 내가 확인한 뒤에, 지역마다 바꿔 낄 부분만 따로 만들어 주세요.
전체를 새로 만들지 말고, 바뀌는 슬라이드만 교체하는 방식으로 합니다.

- 사실과 해석이 구분되어 있습니다.
