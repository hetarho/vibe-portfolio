# HTML 연습장

대면 수업에서 학생이 코드를 쓰는 동안 강사가 옆에서 지켜보며 어디서 막히는지 찾는 용도입니다.
화면을 반으로 나눠 학생은 왼쪽에서 코드를 쓰고, 오른쪽에서 그 결과를 봅니다.
`js-practice-to-code` 수업에서 채우는 파일과, 카드별로 나눈 몸풀기 다섯 개가 들어 있습니다.
몸풀기는 수업 첫머리에 풀게 하면 어느 카드가 비어 있는지 바로 보입니다.

백지 앞에서 첫 줄을 못 떼는 학생을 위한 **1~4시간 코스**(`drill/`)도 있습니다.
같은 문제를 Step 1(보고 치기)부터 Step 5(백지)까지 다섯 번 치면서 힌트를 하나씩 지웁니다.
시간 배분, 발문, 멈췄을 때 대처는 [TEACHING_GUIDE_4HOURS.md](TEACHING_GUIDE_4HOURS.md)에 있고,
같이 띄우는 강의 화면은 `/lesson/js-blank-page-drill`입니다. 강의 화면은 이 폴더의 step 파일을 그대로 읽어서 보여 줍니다.

## 화면 나누기

1. 터미널에서 개발 서버를 켭니다. 이미 켜져 있으면 넘어갑니다.

   ```bash
   pnpm dev
   ```

2. VS Code에서 `Ctrl+Shift+P`를 누르고 `Simple Browser: Show`를 고른 다음, 주소에 `http://localhost:3030/html-practice/`를 넣습니다.
3. 열린 Simple Browser 탭을 오른쪽으로 보냅니다. `Ctrl+Alt+→`를 누르거나 탭을 끌어 편집 영역의 오른쪽 가장자리에 놓습니다.
4. 왼쪽에서 연습할 파일을 열고, 오른쪽 목록에서 같은 파일의 「문제」를 누릅니다.
5. 왼쪽에서 고치고 `Ctrl+S`로 저장하면 오른쪽이 저절로 새로 고쳐집니다.

브라우저 창을 따로 쓰고 싶으면 크롬에서 같은 주소를 열고 `Win+→`로 화면 오른쪽 절반에 붙입니다. VS Code는 `Win+←`로 왼쪽 절반에 붙입니다.

개발 서버 없이 파일을 브라우저로 바로 열어도 됩니다. 이때는 저장한 뒤 `F5`로 직접 새로 고칩니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html` | 오른쪽에 먼저 띄우는 목록. 4시간 코스 → 정규 수업 순서 |
| `00-blank.html` | 타자 연습장. 껍데기 패턴 A(if-else) · B(값 가져오기 + 조건문) · C(함수 + 조건문) · D(for)를 다섯 판 연속으로 칩니다. 이 파일은 고치지 않고 화면에서 칩니다 |
| `drill/` | 4시간 코스. 문제마다 `step1~5.html`, 4교시는 `07-cart/cart.html`. 정답과 채점 값은 `drill/problems.js`, 화면 장치는 `drill/drill.js` |
| `TEACHING_GUIDE_4HOURS.md` | 4시간 코스 강사용 가이드 |
| `lesson/` | 오늘 수업에서 채우는 파일. 1부 `practice1~5.html`, 2부 `menu` · `stock` · `attend` |
| `warmup/` | 몸풀기 다섯 개. 뒤로 갈수록 미리 써 둔 것이 줄어듭니다 |
| `answers/` | 몸풀기 정답과 장바구니 정답(`cart.html`). 오늘 수업 정답은 `src/pages/lesson/content/js-practice-to-code/answers/`에 있고, 목록의 「정답」이 그 파일을 엽니다 |
| `00-template.html` | 새 문제를 풀 때 복사해서 쓰는 빈 연습장. 3단계 사고 프레임워크(재료 준비 → 껍데기 먼저 → 빈칸 채우기)가 주석으로 들어 있습니다 |

문제는 파일 맨 위 주석에 있습니다. 「작은 경우로 확인」에 적힌 값을 넣어 보고 맞으면 끝입니다.
`lesson/` 파일의 script 안에는 선생님과 같이 채우는 3단계 틀이 주석으로 들어 있습니다.

## 4시간 코스

| 교시 | 파일 | 내용 |
|---|---|---|
| 매 교시 시작 | `00-blank.html` | 껍데기 다섯 판 치기 (3교시는 `#D`) |
| 1교시 | `drill/01-greeting` · `drill/02-candy` | if / else 한 번 |
| 2교시 | `drill/03-login` · `drill/04-stock` | else if 여러 갈래, 함수 밖 그릇 |
| 3교시 | `drill/05-candy-row` · `drill/06-scan` | for로 li를 만들어 화면에 쏙쏙 넣기 |
| 4교시 | `drill/07-cart/cart.html` | 장바구니 조립. 이벤트 연결 · 에러 처리 · 계산 · 출력 빈칸 |

Step 화면에는 문제 설명, 복사가 막힌 정답(Step 1), 정답 5초 보기(Step 2~5), 체크리스트(Step 5), 「채점하기」가 붙습니다.
코드에 오류가 나면 몇 번째 줄인지와 한국어 힌트를 화면에 띄우므로, Simple Browser에서도 콘솔 없이 고칠 수 있습니다.
채점을 통과한 Step은 목록과 Step 화면에서 초록색이 됩니다. 이 기록은 그 브라우저에만 남습니다.

문제 문장이나 정답을 바꾸려면 `drill/problems.js`를 고치고, 같은 문제 폴더의 `step2~4.html` 빈칸과 주석도 맞춰 줍니다. 강의 화면도 같은 파일을 읽으므로 따로 고칠 필요가 없습니다.

## 지켜볼 곳

학생이 멈추면 답을 말하기 전에 먼저 "지금 다섯 단계 중 몇 단계야?"라고 묻습니다.
대답을 못 하면 절차(3단계)가 없는 것이고, 단계는 말하는데 코드가 안 나오면 그 줄의 카드가 비어 있는 것입니다.

| 파일 | 자주 막히는 곳 | 답 대신 던질 질문 |
|---|---|---|
| `01-greeting` | `.value`를 빼서 "[object HTMLInputElement]님"이 나온다 | 칸에서 꺼낸 게 칸이야, 칸에 적힌 글자야? |
| `02-candy` | 몫(`/`)과 나머지(`%`)를 헷갈린다. `Number`를 빼도 이 문제는 맞게 나와서 빠뜨린 줄 모른다 | 왜 `Number`를 썼어? 빼면 어떻게 돼? |
| `03-tabs` | `getElementById('kind')`처럼 매개변수에 따옴표를 붙인다. 숨기기를 빼서 창이 쌓인다 | `kind`에는 지금 무엇이 들어 있어? |
| `04-todo` | 그릇을 반복 안에서 `let done = 0`으로 만든다. 반복이 끝나면 `done`이 없어서 아무것도 안 나온다 | 그릇의 처음 값은 언제 한 번만 정해야 해? |
| `05-login` | 버튼에 `onclick`을 안 건다. `return`을 빼서 알림창이 연달아 뜬다. `&&` 자리에 `\|\|`를 써서 admin / 1111이 통과한다 | 버튼을 누르면 어떤 함수가 실행돼? 알림 뒤에 어디까지 실행돼? |

Simple Browser에서는 오류 메시지가 보이지 않아서, 버튼을 눌러도 아무 일이 없으면 이유를 알기 어렵습니다.
그럴 때는 같은 주소를 크롬에서 열고 `F12` → Console을 학생과 같이 봅니다. 오류 메시지를 읽는 것도 연습입니다.
