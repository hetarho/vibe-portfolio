2. 한 문제를 다섯 번 칩니다

Step 1 · 보고 치기위에 정답이 보입니다. 복사는 막혀 있으니 한 글자씩 칩니다.
Step 2 · 값만 바꾸기뼈대는 다 있습니다. 노란 ___ 자리만 채웁니다.
Step 3 · 주석 보고 채우기if 껍데기와 한국어 주석이 있습니다. 주석 아래에 씁니다.
Step 4 · 주석만한국어 주석만 있습니다. 껍데기부터 치고 주석을 안으로 옮깁니다.
Step 5 · 백지아무것도 없습니다. 주석 → 껍데기 → 빈칸 순서로 씁니다.

Step 1을 통과하면 다음 Step 버튼이 나옵니다. Step 5까지 통과하면 다음 문제로 넘어갑니다.

3. 순서 한 교시 = 약 1시간 · 1시간만 해도 끝맺음이 됩니다

4. 막혔을 때 · 한 칸씩 내려갑니다

  1. 검은 상자를 소리 내어 읽습니다. 이번 Step에서 할 일이 한 줄로 적혀 있습니다.
  2. 다음에 할 일을 한국어로 말합니다. 말이 나오면 그대로 // 주석으로 씁니다.
  3. 속은 비우고 껍데기만 칩니다. if () { } else { } · 손이 움직이면 머리가 풀립니다.
  4. 「정답 5초 보기」를 누릅니다. 5초 뒤에 다시 가려집니다.
  5. 한 Step 내려갔다가 다시 올라옵니다. 맨 위 동그라미에서 아래 번호를 누릅니다. 실패가 아니라 순서입니다.

5. 선생님용 · 노트북 한 대로 진행하기

브라우저 탭 두 개만 씁니다
  1. 탭 1 · 강의 화면 · 교시를 시작할 때와 문제를 처음 소개할 때만 띄웁니다. 숫자 키 1~4로 교시 시작 화면으로 갑니다.
  2. 탭 2 · 이 코스 화면 · 학생이 칠 때는 이 탭에 둡니다.
  3. 탭 사이는 Ctrl + Tab으로 오갑니다. 키보드는 학생 앞에 두고, 선생님은 옆에서 화면만 가리킵니다.
  4. 매 교시 시작 5분은 타자 연습장에서 껍데기를 다섯 판 칩니다.
