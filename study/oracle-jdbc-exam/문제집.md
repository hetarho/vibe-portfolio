# Oracle SQL~JDBC 시험 대비 문제집 (200문제)

## 사용 기준

- 범위: 제공된 Oracle 18c XE, SQL, 함수, GROUP BY/HAVING, JOIN, SUBQUERY, DDL, DML, SEQUENCE, JDBC 자료.
- 형식: 예시 시험과 같이 하급 6점, 중급 11점, 상급 16점. 실제 시험의 출제 비율과 배점이 정해졌다는 뜻은 아니다.
- SQL 문법은 Oracle 기준이다. 별도 지시가 없으면 `EMPLOYEE(EMP_ID, EMP_NAME, EMP_NO, EMAIL, PHONE, DEPT_CODE, JOB_CODE, SALARY, BONUS, MANAGER_ID, HIRE_DATE, ENT_YN)`, `DEPARTMENT(DEPT_ID, DEPT_TITLE, LOCATION_ID)`, `JOB(JOB_CODE, JOB_NAME)`, `LOCATION(LOCAL_CODE, LOCAL_NAME)`을 사용한다.
- 결과 예측용 표본은 실제 KH 데이터가 아니다. `EXAM_EMP(ID, DEPT, SALARY, BONUS)`의 행은 `(1,'D1',100,0.1)`, `(2,'D1',200,NULL)`, `(3,'D2',300,0.2)`, `(4,NULL,400,NULL)`이다. 결과의 행 순서는 `ORDER BY`가 있을 때만 보장된다.
- 161~180번은 워크북의 춘대학교 테이블을 쓴다. `TB_DEPARTMENT(DEPARTMENT_NO,DEPARTMENT_NAME,CATEGORY,CAPACITY)`, `TB_STUDENT(STUDENT_NO,DEPARTMENT_NO,STUDENT_NAME,ENTRANCE_DATE,ABSENCE_YN,COACH_PROFESSOR_NO)`, `TB_PROFESSOR(PROFESSOR_NO,PROFESSOR_NAME,DEPARTMENT_NO)`, `TB_CLASS(CLASS_NO,DEPARTMENT_NO,CLASS_NAME,CLASS_TYPE)`, `TB_CLASS_PROFESSOR(CLASS_NO,PROFESSOR_NO)`, `TB_GRADE(TERM_NO,CLASS_NO,STUDENT_NO,POINT)`을 사용한다. 원본 테이블의 다른 열은 [Table기술서](/Users/ihaelam/Downloads/Table기술서.pdf)에 있다.
- 문제에서 말하는 `NULL`은 SQL의 `NULL`이다. 문자열 및 날짜 형식은 명시된 형식으로 판단한다.
- 각 문제는 독립적이다. 한 문제에서 만든 테이블 또는 변경 사항을 다음 문제의 초기 상태로 이어서 적용하지 않는다.
