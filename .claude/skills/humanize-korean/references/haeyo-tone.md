# 해요체 (토스 스타일) — 문체 프리셋

`문체: 해요체` 옵션이 붙었을 때만 로드한다. 기본 동작(register 보존)을 **의도적으로 덮어쓰는** 유일한 프리셋이다.
평소 humanize-korean은 격식체 입력 → 격식체 출력을 지키지만, 이 프리셋에서는 종결어미를 해요체로 통일한다.

출처: 토스 [8가지 라이팅 원칙](https://toss.tech/article/8-writing-principles-of-toss),
[토스 UX Writing 인터뷰](https://toss.im/tossfeed/article/uxwriter-interview)

---

## 0. 대전제

> **"니다체가 아니라 해요체를 씁니다."**

토스는 앱 전체를 한 사람의 목소리로 유지하려고 종결어미를 해요체로 고정한다.
합쇼체(-습니다/-입니다)와 해요체가 섞이면 그 자체로 톤이 깨진다. **한 화면 안에서는 반드시 하나로 통일한다.**

해요체 = 반말이 아니다. 존댓말이되 소리 내어 말할 때의 높이다.

## 1. 종결어미 변환표

| 합쇼체 | 해요체 | 비고 |
|---|---|---|
| ~입니다 | ~예요 / ~이에요 | 받침 없으면 예요, 있으면 이에요 |
| ~습니다 / ~ㅂ니다 | ~어요 / ~아요 / ~해요 | |
| ~합니다 | ~해요 | |
| ~됩니다 | ~돼요 | |
| ~있습니다 / ~없습니다 | ~있어요 / ~없어요 | |
| ~했습니다 | ~했어요 | |
| ~할 것입니다 | ~할 거예요 | |
| ~하십시오 / ~하시기 바랍니다 | ~하세요 / ~해주세요 | |
| ~합시다 | ~해요 / ~할게요 | 청유는 "~할게요"가 더 부드럽다 |
| ~하지 마십시오 | ~하지 마세요 | |

**주의:** 형용사 어간이 해요체에서 명령형과 겹치면(세다 → 세요, 켜다 → 켜요) 어휘를 바꾼다.
"이야기 하나가 더 셉니다" → ✗ "더 세요" → ○ "훨씬 강해요".

## 2. 문어체 종결(-ㄴ다/-다)의 처리

카드 제목·리스트 항목처럼 **명사구로 끝나는 라벨은 그대로 둔다.** 문장으로 읽히는 것만 해요체로 바꾼다.

- "데이터와 규칙을 다룬다" → "데이터와 규칙을 다뤄요" (문장)
- "전환 비용은 생각보다 낮다" → "전환 비용은 생각보다 낮아요" (문장)
- "시장 얘기 정면 돌파" → 그대로 (명사구 라벨)

명사형 종결(~함, ~됨, ~임)은 해요체와 절대 못 섞인다. 전부 문장으로 편다.
- "누군가 근거를 갖고 채점하고 설명을 요구함" → "채점은 근거를 대고, 설명까지 요구해요"

## 3. 번역투·의문형 제목 정리 (해요체와 같이 처리)

해요체 전환에서 제일 많이 남는 잔재가 **영어 제목 직역**이다.

| 잔재 | 정체 | 고침 |
|---|---|---|
| "어떻게 읽으면 되나" | How to read → 직역 | "이렇게 읽으면 돼요" |
| "어떻게 설계되어 있나" | How it's designed | "이렇게 설계했어요" |
| "~인가 / ~하는가 / 모르는가" | 논설조 설의법 | 평서문으로: "시간 가는 줄 몰랐는지" |
| "무엇을 의미하는가" | What it means | "무슨 뜻이냐면요" |
| "~에 대해 알아봅시다" | Let's learn about | "~를 볼게요" |

## 4. 토스 8원칙 (해요체와 함께 적용)

1. **Predictable hint** — 다음에 뭐가 나올지 예상되게 쓴다. 혜택만 말하고 동작을 안 알려주지 않는다.
2. **Weed cutting** — 있으나 없으나 같은 단어를 지운다. "앞으로 계속" → "계속".
3. **Remove empty sentences** — 제목에서 한 말을 설명에서 또 하지 않는다. 공간이 비어 보인다고 문장을 채우지 않는다.
4. **Focus on key message** — 이미 아는 정보는 과감히 뺀다. 지금 확인할 것만 남긴다.
5. **Easy to speak** — read가 아니라 **speak**. 소리 내어 읽어서 안 걸려야 한다. 한자어·문어체·긴 호흡 금지.
6. **Suggest over force** — 겁주거나 강요하지 않고 권한다. "놓치면 손해" → 선택지를 중립적으로.
7. **Universal words** — 유행어·은어·밈 지양. 나이·전공이 달라도 같은 뜻으로 읽히게.
8. **Find hidden emotion** — 정보 뒤의 감정을 읽는다. 다 갚은 사람에겐 잔액이 아니라 "축하해요"를 먼저.

## 5. 해요체 특유의 리듬 (AI 티 방지)

해요체로 바꾸기만 하고 문장 구조를 그대로 두면 "존댓말 입힌 번역투"가 된다. 같이 손본다.

- 접속부사(그러나·따라서·또한)를 줄이고 문장을 끊는다. → "근데", "그래서", 또는 그냥 마침표.
- 종결 다양화: `~예요` 연타 금지. `~거든요 / ~잖아요 / ~더라고요 / ~어요 / ~할게요 / 명사 종결`을 섞는다.
- 짧은 문장 하나를 문단마다 심는다. ("이게 전부예요.")
- 청자를 부른다: "~해보세요", "~잖아요" — 단, 3~4문단에 한 번 정도로.

## 6. 하지 말 것

- 해요체 + 합쇼체 혼용 (같은 화면·같은 문단 안에서 특히)
- 반말로 내려가기 ("~해", "~야") — 해요체는 존댓말이다
- 애교·감탄사 남발 ("~해요!!", "~죠?~", 이모지) — 토스 톤은 친근하되 담백하다
- 기계 출력·터미널 로그·인용문의 어미 변경 (Do-NOT list 그대로 적용)
- 용어를 쉬운 말로 바꾼답시고 내용 앵커(고유명사·개념어)를 갈아치우기
